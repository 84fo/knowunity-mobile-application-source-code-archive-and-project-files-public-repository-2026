# حالة الاستعادة

تم استخراج الموارد وملفات Smali كاملة عبر Apktool. تم استخراج ملفات Java-like عبر JADX مع أفضل محاولة ممكنة؛ قد تبقى بعض الملفات غير المفككة بسبب تعقيد/حجم مكتبات APK، ويمكن الرجوع إلى `apktool/smali*` لتلك الأجزاء.

هذا الناتج ليس مشروع Android Studio أصليًا قابلًا للبناء مباشرة: APK لا يحتفظ بملفات Gradle الأصلية، ولا بكود Kotlin الأصلي والتعليقات وأسماء المصدر قبل التحسين. استخدمه كنقطة استعادة لإعادة إنشاء المشروع وتنفيذ التعديلات.
