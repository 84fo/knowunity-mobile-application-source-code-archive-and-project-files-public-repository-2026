# Knowunity — نسخة مستعادة من APK

هذه النسخة ناتجة عن تفكيك ملف `Knowunity.apk`.

## المجلدات
- `jadx/`: الكود المفكك بصيغة Java-like، مناسب للبحث والفهم وإعادة البناء اليدوي.
- `apktool/`: الموارد و`AndroidManifest.xml` وملفات smali المفككة.
- `Knowunity_original.apk`: الملف الأصلي كما تم استلامه.
- `tools/`: الأدوات المستخدمة محليًا، ويمكن حذفها إذا لم تكن مطلوبة.

## ملاحظات مهمة
- ملف APK لا يحتوي عادةً على ملفات Gradle الأصلية أو كود Kotlin الأصلي أو أسماء المتغيرات والتعليقات كاملة.
- الكود المفكك يحتاج مراجعة وإعادة تنظيم قبل أن يصبح مشروع Android Studio نظيفًا.
- لا تستخدم توقيع APK القديم عند إصدار نسخة جديدة؛ أنشئ مفتاح توقيع تملكه أنت.
